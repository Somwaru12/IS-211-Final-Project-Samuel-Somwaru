
# Book Catalogue Web App


## Project Description
A simple web application built using Python and Flask that allows users to search for books using an ISBN and store them in a personal catalogue.
Users can log in, search for books through the Google Books API, view saved books, and delete books from their collection.


## Technologies Used
- Python (flask)
- SQLite (database)
- HTML & CSS
- Google Books API


## Features
- User login system
- Search for books by ISBN (Google Books API)
- Store book details:
  - Title
  - Author(s)
  - Page count
  - Rating
- Display saved books
- Delete books from catalogue
